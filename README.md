# example-project

A **reference project** generated from [project-template](https://github.com/project-templates-org/project-template) and set up with `scripts/bootstrap.sh`. It shows the whole workflow with real data.

| Look at | What it shows |
|---|---|
| [Board](https://github.com/orgs/project-templates-org/projects/3) | Epic → Features / Task / Bug with Priority, Size, Estimate, Iteration and dates; Roadmap view |
| [Epic #1](https://github.com/project-templates-org/example-project/issues/1) | Sub-issues and their progress |
| PR #6 → #7 → #8 | Task #4 going `docs/*` → `development` (squash) → `staging` → `main` (merge commits), closed by `Closes #4` |
| [Release v0.1.0](https://github.com/project-templates-org/example-project/releases/tag/v0.1.0) | Release notes generated from labels; backup branch `release/v0.1.0` |
| Settings → Rules / Environments | The 5 rulesets and the development / staging / production environments |
